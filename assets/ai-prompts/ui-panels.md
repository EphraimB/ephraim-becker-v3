# 🪐 UI PANEL GENERATION PROMPTS

## MASTER PROMPT

Create a functional Mars habitat OS user interface panel.

## RULES
- UI must feel embedded in a real system
- Must be readable and minimal
- No decorative or game-like elements

## STYLE
- NASA mission control inspired
- clean grids and alignment
- muted colors (dark gray, amber, green, blue)
- subtle glow for active elements

## STRUCTURE
- one primary data display
- secondary side metrics
- small control section (buttons/toggles)

## EXAMPLES
- oxygen level display
- system health dashboard
- communication log feed
- environmental status panel
