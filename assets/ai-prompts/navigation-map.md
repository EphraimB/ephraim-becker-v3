# 🪐 HABITAT MAP GENERATION PROMPT

## MASTER PROMPT

Create a Mars habitat navigation map UI.

## RULES
- Must be abstract and diagrammatic
- Not a 3D render
- Not a realistic environment image

## STYLE
- minimal sci-fi systems diagram
- NASA mission planning aesthetic
- node-based layout

## STRUCTURE
- rooms represented as nodes (boxes or circles)
- corridors as connecting lines
- central hub clearly defined
- active room highlighted

## INTERACTION CONCEPT
- clicking a node navigates to that room
- map represents physical spatial layout of habitat
