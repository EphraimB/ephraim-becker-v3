# 🪐 UI PANEL GENERATION PROMPTS

## MASTER PROMPT
Create a functional, glassmorphic Ares City OS user interface panel.

## RULES
- UI must feel like an advanced holographic operating system.
- Must be extremely readable and highly structured (clean alignment and modern grids).
- Avoid grungy, cluttered, or overly busy gamified overlays.

## STYLE
- **Glassmorphic & Holographic HUD**: Uses beautiful backdrop-filter blur effects (`backdrop-filter: blur()`), high transparency, and paper-thin solid borders.
- **Cyber-Luminescent Accentuation**: Sleek cyber-neon trace lines and indicator tabs.
- **Modern Color Palette**: Deep translucent charcoal backgrounds with glowing cyan (Metropolis), emerald green (Biosphere), golden amber (Quantum Net), or premium violet/white (Citizen Suite) accent variables.

## STRUCTURE
- **Primary Data Canvas**: The central visual element (e.g., dynamic grid networks, scrolling logs, or portfolio cards).
- **Diagnostic Sidebar**: Technical indicators, system status feeds, or metric bars.
- **Control Strip**: Glass-button controls, sector warp toggles, or interactive filters.

## EXAMPLES
- Hyperloop transit grid flows (Metropolis Core)
- Climate-shield telemetry & eco-dome botanic metrics (Biosphere Dome)
- Quantum message log buffers & wave telemetry streams (Quantum Net)
- Citizen profile summary & interactive project grids (Citizen Suite)
