# 🪐 Mars Habitat OS — System Context

## 🌌 What This Project Is

Mars Habitat OS is a **fictional operating system simulation** designed as an immersive web experience.

It represents a working Mars base where each room functions as a system interface.

---

## 🏗 Core Concept

The website is structured as a **habitat of interconnected rooms**:

- Each page = one physical room in a Mars base
- Each room has:
  - a unique function
  - a dedicated environment (background image)
  - an interactive UI overlay

---

## 🚪 Core Rooms (v1)

- Command Center → main system overview and navigation
- Life Support → oxygen, pressure, environmental systems
- Communications → messages, logs, external signals
- Habitat Quarters → personal / ambient system space

---

## 🧭 Navigation Concept

Navigation is not traditional web navigation.

Instead:
- Users move through a **habitat map**
- Each room is a node in a spatial system
- Transitions should feel like moving through a physical environment

---

## 🎨 Visual Philosophy

- Inspired by NASA-style functional design systems
- Clean, minimal, high-clarity UI overlays
- Backgrounds are immersive Mars habitat environments
- UI never dominates environment—it floats above it

---

## 🧠 Interaction Philosophy

- UI should feel like control panels inside a real facility
- Information is structured, not decorative
- Feedback is subtle (light, motion, state changes)

---

## ⚙️ Technical Philosophy

- Prefer vanilla HTML/CSS/JS for core system
- Keep dependencies minimal
- Build modular systems that can scale later if needed
- Avoid overengineering early (no unnecessary frameworks in v1)

---

## 🚀 Long-Term Vision

This system may evolve into:
- a fully immersive spatial OS
- interactive simulation environment
- potential XR-compatible interface layer

But v1 focuses on:
> clarity, immersion, and modular structure
